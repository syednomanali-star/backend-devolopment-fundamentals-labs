## Student Details

- Section: 112 (CSE Gen-AI)

## Objective
To implement search and sorting operations using SQLite and Express.js.

## Features
- Retrieve all books.
- Search books by title.
- Sort books by title.
- Sort books by price.
- Combine search and sorting.
- Handle invalid sorting parameters.

## Technologies Used
- Node.js
- Express.js
- SQLite
- JavaScript

## Installation

```bash
npm install
```

## Run the Project

```bash
npx nodemon server.js
```

Server runs at http://localhost:3000.
